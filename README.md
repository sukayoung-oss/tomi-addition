# 또미의 덧셈 톡톡

한 자리 수 덧셈을 연습하는 유아용 웹 놀이예요. 파일 하나(`index.html`)로 동작하고, 또미 이미지와 기능이 모두 안에 들어 있어요.

- 단계 7개: +1 ~ +5 하나씩 더하기, 1~5 · 1~9 섞어서 더하기 (0 포함)
- 문제 수: 5 · 10 · 20문제
- 보기 5개 중 하나를 누르면 바로 채점, 틀리면 동그라미 힌트
- 정답일 때 띵동 효과음 · 칭찬 음성 · 불꽃놀이

GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`
